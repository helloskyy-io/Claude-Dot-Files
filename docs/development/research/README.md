# Research pools

Evidence that drives planning. One directory per topic:

```
<topic>/
├── raw/<paper>.md      one mini-paper per topic
└── synthesis.md        the curated decision deliverable
```

Governed by [`../../standards/research/research_standard.md`](../../standards/research/research_standard.md) — the artifact contract, the source floor, confidence marking, and revalidation intervals.

**Nothing here is binding.** These are findings, not rules. A finding becomes binding only by being codified into a standard through human review. A phase doc may cite a pool as its evidence; it may not treat one as a decision already made.

Produced and maintained by `research.sh` and `research-refresh.sh`. Empty until a phase needs evidence — pools are created when a question is asked, not in advance.
