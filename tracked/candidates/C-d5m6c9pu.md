**PROPOSAL against a VENDORED (MIRROR) standard — it is placed here rather than made, because `docs/standards/research/` must not be edited in this repo and an amendment goes upstream to MDC-Master-Planning then re-vendors.** **The consequence, which is the reason this is a finding and not a note:** §2's rubric (`research_standard.md:53`) describes topic COUNTS and nothing else — Small is *1–2 topics*. It has no vocabulary for the SHAPE of a cycle, so a run reading it to decide how much research to do can size a question correctly at Small and still emit `topics.md`, a fan-out, a synthesis and a verify pass over all of it. **That is not hypothetical: it is exactly what happened.** A portfolio-direction question was assessed as Medium, produced five papers and a synthesis at ~3.5 hours, and the operator called it *"mass overkill"* — and the important half is that **sizing it correctly would not have fixed it**, because the architecture below the rubric does not change with the topic count. **PR #83 built the missing shape (`research_minor`: one paper, no `topics.md`, no synthesis, same `research_verify` and same `research-critic` gate) and deliberately did NOT touch the standard.** So the capability now exists and the document that a run consults to choose it does not mention it — a run following the standard faithfully will never reach the cheaper cycle. **Done-state today: yes, and it is small** — a row or a sentence in §2 stating that a single-concern question with one destination is answered by a one-paper cycle, alongside the existing count rubric. **The bounded part is deliberately excluded from the proposal:** whether the bands themselves should be re-cut is a separate question with its own evidence requirement, and §2 already says a single overrun is an observation rather than evidence. **NOT a defect:** nothing behaves wrongly — the standard is silent, not incorrect, and every §3 per-paper obligation is preserved in full by the new cycle, so a paper it produces is standard-conforming today. **Not an expansion of an existing row:** no candidate concerns the Research Standard's own sizing text. **Not filed as an issue** — it is capability that would be ADDED to a document, which per [`finding-routing.md` § 4](../../docs/standards/finding-routing.md) makes it a candidate whatever its done-state looks like, and the default is against filing.  *(Renumbered from C-xhb460zu on 2026-08-11 — that ID went to an unrelated proposal on `main` while this branch was open.)*  *(Renumbered from C-skkjo6jn on 2026-08-12 — PR #82
