**The live instance is already fixed** (`README.md` said 10 workflows, there are 9 — corrected 2026-08-09); what remains is the check, which is capability. `architectural_standard.md:46` already states the principle — *"a constant restated in two places diverges silently"* — and nothing enforces it. **THIRD OCCURRENCE, with its cost measured, added by PR #71's refine pass — this is the recurrence the row was left open to collect.** The first was this file's own summary block (see the note below §Where things stand); the second, `exit-protocol.md` §4's *"nine rules"* prose beside a table whose reason COLUMN is machine-gated while its rule COUNT is hand-typed; the third, `file_structure.txt` restating that same count as *"the nine-rule fail-safe contract"* and **going stale for a whole pass** after R0 landed, in the file `CLAUDE.md` calls authoritative. Note the pattern the three share: in every case the *contents* had a gate and the *count* did not, so each divergence was invisible to a green suite. **The cost is now known: three hand-corrections across two passes on one PR, each found by a reader rather than a check.** **FOURTH OCCURRENCE, 2026-08-10, and this one was caught BY A CHECK — which is the most useful thing the row has collected yet.** The run closing [Phase 3](../../../development/memory-management-framework/phase3_typed_exit_record.md) restated that phase's fresh agreement figures in `roadmap.md`, and `testing/scripts/tests/unit/test_measurement_figures_are_cited.py` went red. **It fired by accident, not by scope:** that gate is scoped to *Phase 5* lines, and it only saw these because the roadmap's status header names both phases on one line — the figures the same run put on the **Phase 3 checkbox line were invisible to it**, and were removed only because the accidental catch prompted a re-read. So the gate proves the mechanism is real, gateable and cheap to check, **and simultaneously proves the hand-kept-scope defect this file keeps recording**: a check whose subject is one enumerated phase retires itself the moment the next phase produces figures. **That run's OWN two instances are fixed — both roadmap mentions are now pointers — but the roadmap is NOT clean, and saying so is the point of this entry.** Running the gate's own regex over the whole file instead of its Phase-5 scope returns **two pre-existing restatements it has never seen**: `roadmap.md:149` carries Phase 1 E3(b)'s `6 of 7` and `31 of 38`, and `:170` carries candidate 6's `8 archived PRs`. Both predate that PR (verified at branch point `799e0f9`) and both were left unfixed as outside a measurement-recording task's scope at the time this paragraph was written — **recorded here so the count is honest rather than implied clean.** **Both are now fixed, by this same PR's second correction pass: both roadmap mentions are pointers, and the widened gate (sixth occurrence, below) is green over the whole file.** They were the standing evidence for the candidate when this paragraph was written; that evidence is now historical rather than live, which does not weaken the candidate — the sixth occurrence's argument is that the mechanism keeps recurring, not that these two offenders remain, and it recurred twice more in this same PR after this paragraph was first committed. The candidate is unchanged and better evidenced — **derive or cite, never restate, and scope the check to the SHAPE rather than to a list of phases someone remembered.** **FIFTH OCCURRENCE, same PR, one pass later, and it is the one that should decide this row: the restatements were left behind by the FIX for the fourth.** PR #79's review pass found that flipping Phase 3's status had left copies contradicting the flip — `roadmap.md`'s trailing Phase-3 paragraph still read *"BUILT, NOT YET PROVEN … seven of eight"* four lines below the checkbox flipped to *"both halves done"*, and the phase doc's close-out still justified leaving standards-candidate 1 alone because *"requirement 6 has not yet done"* it, two bullets under the box asserting requirement 6 was met. **Both are fixed; neither was reachable by any gate.** They carry no denominator figure, so the shape-matching check this row proposes would not have caught them either — **a completion VERDICT is restated exactly like a count and nothing in the proposal covers it.** That is new information about the candidate's scope, not just another tally mark: *three independent reviewers each found one of these by reading, in a PR whose own diff was expanding this row about that exact mechanism.* **The candidate should be ruled to cover restated STATUS as well as restated COUNTS, or it will ship a check that leaves the more consequential half uncovered.** *(That paragraph originally reported the population as "three of the five places"; the true population is **nine** assertion sites — four in the phase doc, three in `roadmap.md`, one in `file_structure.txt`, one in `phase5_convergence_stopping.md` — and the count was itself a restatement of something nobody derived, inside this row. Corrected 2026-08-10.)* **SIXTH OCCURRENCE, and it is the fifth's own fix leaving survivors: the pass that WROTE the fifth-occurrence paragraph above missed two sites two files over.** `file_structure.txt:97` still read *"Phase 3 BUILT-NOT-PROVEN … 7 of 8 requirements"* and `phase5_convergence_stopping.md:155` still read *"Requirement 6 of Phase 3 is still open"* — the second being a **gate condition that the same PR fired**. All four review lenses on PR #79's second correction pass found them independently; none was reachable by any check. Both are now fixed. **Two things this row did not have before, and they are what a ruling needs:** (1) **the roadmap half of the proposal is now BUILT and shipped in PR #79** — `test_measurement_figures_are_cited.py` no longer scopes its roadmap sweep to *Phase 5* but enumerates every `phase*.md` on disk, so a figure restated beside any phase's name fails; measured on the tree at the time, it found exactly the two pre-existing offenders named above and **zero** false positives. (2) **The STATUS half is NOT gateable the same way, and this is measured rather than assumed.** A prototype keyed on line co-occurrence — a line naming a phase whose doc declares itself COMPLETE, plus a not-done token — returned **9 hits of which only 2 were real**: it fires on `roadmap.md:3` (which correctly says Phase 4 is unstarted), on a candidate note quoting historical text, and on a line saying a *gated item* still does not land. **So "restate a status" has no syntactic signature the way "restate a count" does**, and ruling this row `ship` on the assumption that one mechanism covers both would produce a gate people disable. The two halves should be ruled separately: the count half is done, the status half needs a different mechanism (most likely a declared canonical status field per phase doc, compared rather than pattern-matched). **FOURTH THROUGH SEVENTH OCCURRENCE, and the first one where the mechanism was measured to be NON-CONVERGENT — PR #75.** Four consecutive passes over that PR each headlined this same defect and each fixed the instances it could see: the draft pass wrote *"a summary line is a copy, and a correction that lands in the source without landing in its copies has not landed"* in its own reflection and then violated it five times in the same PR; the refine pass fixed those five and re-introduced it wherever ITS OWN corrections had copies; the review pass found four more, including two in the roadmap — the file a later run reads to learn what is proven — and one where a document contradicted itself twelve lines apart; and the correction pass after that found four again, one of them a **withdrawn argument** rather than a stale number (a justification the phase doc explicitly deleted as motivated reasoning, still standing in the roadmap as support). **The frontier moved every time and never shrank, which is the evidence this row was left open to collect: fix-the-instances does not converge on this class, and that is now measured rather than argued.** **What DID close it, and it is the shape this candidate should be ruled on:** a check keyed on the class instead of the instances — figures with a denominator may appear only in the section that takes the measurement, and every other mention is a citation. Two such gates now ship for one corpus (`testing/scripts/tests/unit/test_measurement_figures_are_cited.py`), both mutated in both directions. They cost about a hundred lines and they close the mechanism for the documents they cover; **the candidate is whether that shape generalises to the roster and inventory counts this row was originally about**, which is a decision and not a task. Note also that the check does NOT ask any prose to be correct — no test can check that — only that a derived figure live in one place, which is what makes it implementable at all
