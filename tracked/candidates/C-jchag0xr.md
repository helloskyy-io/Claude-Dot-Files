**Phase 5 enumerated five ways a convergence signal can be fooled and built a check for four; this is the fifth, named as unmitigated rather than smoothed over.** `review-pr` authors `findings[].disposition`; Phase 5's predicate reads it; a reviewer that marks `fixed` what is not fixed makes the predicate agree, silently. **Re-verified as a PROPOSAL at placement, not a defect:** nothing behaves wrongly today — the computed signal agrees with the incumbent flag on every assessable block, and no fire has been observed to be early. **Both figures and their denominators are in [Phase 5 § Measurement](../../docs/development/memory-management-framework/phase5_convergence_stopping.md), and the second one must not be quoted bare: the self-reported early-fire counter is CIRCULAR** — it is scored on a verdict the same pass wrote, so it cannot move for the very mode this candidate is about — and the observed counter has an empty denominator. This row's proposal-not-defect classification rests on *nothing behaves wrongly*, which the agreement figure supports; it does **not** rest on the early-fire zero, and an earlier version of this Note quoted that zero as though it did — and *"we have no check for X" is not a defect in X*, the distinction the C-j7pagwn3/C-2t2qw8nm placements already turn on. **Consequence of leaving it:** the convergence signal stays permanently ungateable. Phase 5 declines to route on it *for this reason*, so the mode is not a risk today — it is the thing standing between the signal and the exit-criteria milestone [Autonomous Operation](../../docs/development/autonomous-operation/autonomous-operation.md) is waiting on. **Why it is not C-rrm2t4sj expanded:** C-rrm2t4sj asks what to do when a verification COULD NOT RUN. This asks for a verification that DOES NOT EXIST. Same shape at a glance, different mechanism and different remedy — and C-rrm2t4sj's own Note draws exactly this line when it separates the policy half from the defect half. **No done-state today and no phase owns it — and the first version of this sentence was WRONG, which is recorded rather than quietly fixed.** It read *"`grep -n 'disposition' phase4_fleet_migration.md` returns nothing"*; the grep actually returns **three** lines, and the claim was written from expectation instead of from the command. Run at placement, the three are: `:55` naming the `disposition.md` prompt file as a migration surface, `:77` on selecting a `pr_review:` block by run nonce, and `:104` on a parity table. **None is a home for this** — all three are about *addressing and migrating* the record, none about *verifying that a disposition claim is true* — so the conclusion stands and its evidence did not. The lesson is the one this repo keeps re-learning: a grep quoted without being run is a citation to nothing, and a correct conclusion resting on a false premise is one edit from becoming a wrong one. The remedy is a decision, not a task — the only known mechanism is a second actor re-checking a sample of `fixed` claims, which is a second review with its own cost, and whether that is worth buying is an operator call **Lens verdicts (`finding-routing.md` §5 gate 4).** `/decide`: BUILD-LATER — the root cause is that one actor both writes and reads `disposition`, and the only remedy that touches the root is a second actor; every cheaper variant (a heuristic on finding text, a diff check) verifies the artifact rather than the claim and would be a fifth thing to trust. `/best-practices`: independent verification of a self-reported completion is standard where the reporter has an incentive (audit sampling, four-eyes release sign-off), and the standard form is a SAMPLE rather than a re-review of everything — which is what makes it priceable at all. Both point the same way: real, not urgent while nothing routes on the signal, and the sizing question is the sample rate.
