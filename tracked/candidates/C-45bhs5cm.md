**FIXED 2026-08-14 by hand: the pair is now recorded on the failure path too, so the denominator is no longer conditioned on the prose channel succeeding. Three tests, mutation-checked.** **Phase 3's run set is nine live dispatches and the instrument recorded eight.** The ninth emitted a valid typed record and no prose `VERDICT:` line, so `run_claude`'s completion gate raised **before `route()` and before `append_parent_route`** and the pair was never compared. **The run's identity, turn count, exact last text block and root cause live in [step 7b's row-1 account](../../docs/development/memory-management-framework/phase3_typed_exit_record.md#step-7b--the-run-set-nine-live-dispatches-and-the-three-numbers-it-yields) and are deliberately not retyped here** — an earlier version of this Note carried its own copy of them, which is this file's own C-523klr8n mechanism occurring in the file that holds C-523klr8n, and it went stale the moment the row-1 cause was corrected. **Consequence:** `channels_agree` can only ever be written on runs where the incumbent prose channel already succeeded, so the instrument built to weigh prose against the typed record is **structurally blind to prose's own failure mode**, and its agreement figure is conditioned on the very thing it is measuring. One dispatch in nine hit this, so the condition is not vacuous — **though that is not an incidence rate**, since the proximate cause was removed inside the measurement window and did not recur — and **no larger N removes the blindness itself** — [Phase 4](../../docs/development/memory-management-framework/phase4_fleet_migration.md) widening the denominator inherits the same blindness, which is what makes this worth placing rather than noting. **Re-verified as a PROPOSAL, not a defect — and the supporting sentence needed correcting to survive that re-verification.** It read *"nothing behaves wrongly"*, which is false about the motivating instance: **a real defect produced it — Phase 3's own Stage 6 ordering put the record's tool call last, and a tool call is a terminal action — and it was fixed on `main` by `fb85c3e` thirteen minutes later.** *What makes this a proposal is that the OBSERVATION GAP survives that fix.* The completion gate can raise for any reason — an early stop, a truncated turn, a model that stops after any terminal-feeling action — and on every such path `append_parent_route` structurally cannot write a route the parent has not computed. The fail-loud contract itself worked exactly as designed: the run failed, an operator saw it, the work was redone on the next dispatch. **So the row is stronger than the version it replaces, not weaker:** it no longer rests on the claim that the instance was causeless, which was the one claim in it that a reader could falsify. The remedy is a **new observation point** on the gate-failure path, recording that the child produced a record while the prose channel did not; that is capability that does not exist, and *"we have no measurement of X" is not a defect in X*, the same line the C-j7pagwn3/C-2t2qw8nm/C-jchag0xr placements turn on. **Not C-rrm2t4sj expanded, and the distinction is the stage:** C-rrm2t4sj asks what to do with a verification that could not run **after** the route was persisted; this is a comparison that never started because the route was never computed. Different mechanism, and C-rrm2t4sj's remedy vocabulary (annotate / record / downgrade an existing note) does not produce this one. **No done-state today:** what a parent should record when its child fails the *incumbent* contract is unruled, and making it durable needs a stratum for *"the run did not get far enough to route"* that [`exit-protocol.md` §2](../../docs/standards/exit-protocol.md) does not have — the same shape as C-rrm2t4sj's blocker, which is why both wait on the same ruling. **Lens verdicts (`finding-routing.md` §5).** `/decide`: **BUILD-WITH-PHASE-4** — the five-whys bottoms out at *the incumbent channel's emission is a prompt instruction with no schema enforcement* (step 8 already names it as the weaker half), and the instrument that would measure that weakness sits **downstream of the gate that enforces it**; the remedy only earns its stratum where the denominator is meant to become a rate, which Phase 3 explicitly declines to be. `/best-practices`: this is **survivorship bias** in a channel A/B comparison — a named measurement-design defect — and the standard remedy is to record at the point of **assignment** rather than of **completion** (the intention-to-treat discipline), which maps directly onto recording the pair when the dispatch returns rather than when it clears the incumbent's gate. Both say the same thing: real, cheap in principle, not urgent while nothing reports a rate, and **load-bearing the moment Phase 4 states one**. **Nor is it step 4's already-fixed gap wearing a new name, and the phase doc's [step 7b](../../docs/development/memory-management-framework/phase3_typed_exit_record.md#step-7b--the-run-set-nine-live-dispatches-and-the-three-numbers-it-yields) now rules that distinction rather than leaving it to a reader:** step 4's was reachable by moving an append that already ran on the path, so it was repaired on the spot; this one sits upstream of any route being computed, so there is nothing to move. Same principle, different reach — which is what separates a repair from a proposal, and the reason a reader who spots the resemblance should not read this placement as motivated.
