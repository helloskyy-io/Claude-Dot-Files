- **A FINDING NAMES A SITE. FIX THE CLASS.** Before you call an item closed, search the component for the same claim shape and the same defect shape, and **state the site count in your report** — including when it is one. The finding told you where somebody looked, never where the defect is.
- **State whether your sweep was EXHAUSTIVE or a SAMPLE**, and how you searched. *"Four of an unknown total"* is actionable; *"four sites"* asserts a closure you did not establish, and the next reviewer inherits it.
- **Measured, and it is the dominant cost in this loop.** Across two repos on 2026-08-28: one claim fixed at 4 sites, then 4 more, then 3 more — **11 in total, found across three separate review passes**, each pass correctly fixing what it was told about. A review that found *"a ruling with no address"* twice wrote a runway naming those two; the third cost a whole extra pass. **Roughly a third of all holds were repeat members of a class already identified.**
- **It is not a skill problem and knowing about it is not enough.** The same failure hit an autonomous dispatch, an operator working carefully by hand, and a session that had written the finding up an hour earlier. **The sweep is a step, not an intention** — run the search, put the number in the report.
