# Claude Document Index

This file is the master index for everything stored in the `Claude` folder. Each entry lists the path, the document name, and a one-line description of what it contains. Keep this file updated whenever documents are added, renamed, moved, or removed — it's the map the "my document intelligence" skill reads first.

## Index format

`<subfolder>/<file name> — one-line description of contents.`

---

## Health and Fitness

- `Health and Fitness/Puma Workout — Puma's current lifting split: exercises, sets, reps, and rotation schedule.`

---

## How to maintain this index

- **Adding a document:** create the file in the appropriate subfolder, then add a matching line under that subfolder's heading here.
- **New topic area:** add a new `## Heading` section for the subfolder, then list its files beneath it.
- **Renaming or moving:** update the path and name in the corresponding line so it matches the actual file.
- **Removing:** delete the line for any document removed from the folder.
- Keep descriptions to a single, specific sentence so the skill can quickly judge relevance.
